# Prosit

**A deep-learning system for predicting peptide tandem mass spectra and retention properties.**

## Overview

Prosit is a widely used prediction tool for spectral library generation and search enhancement in proteomics analysis.

## Key Features

- **Spectrum Prediction**: High-quality in silico fragment intensity prediction.
- **Library Augmentation**: Supports DIA/DDA identification workflows.
- **Use in Search**: Predicted spectra can support rescoring; gains depend on model and dataset.
- **Environment**: Follow the official release requirements; operating-system support depends on the package and its dependencies.

## Input/Output

**Input:**

- Peptide sequences and charge states
- Optional modification settings

**Output:**

- Predicted MS/MS spectra and related properties
- Library-ready prediction tables
