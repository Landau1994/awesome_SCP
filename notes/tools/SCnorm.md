# SCnorm

## Overview

SCnorm is an R/Bioconductor package originally designed for normalization of single-cell RNA-seq count data, accounting for gene-specific relationships between expression and sequencing depth.

## Conditions and Limitations

Its original statistical setting is RNA counts. Use in MS proteomics needs explicit adaptation and validation; extreme sparsity can limit estimation, and normalized values are not additional measurements.
