# TDValidator

## Overview

TDValidator is Proteinaceous software for targeted top-down spectrum interpretation and fragment-ion validation. The current vendor page states that it is fully integrated into ProSight Native.

## Conditions and Limitations

Inspect the matching ProSight Native release and licensing. Fragment annotations support assessment of a proposed proteoform but do not substitute for appropriate identification confidence and ambiguity reporting.
