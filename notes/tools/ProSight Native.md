# ProSight Native

## Overview

ProSight Native is Proteinaceous software for intact-mass analysis, targeted top-down characterization and analysis of protein complexes, including native and denaturing MS workflows.

## Conditions and Limitations

Results depend on deconvolution, sequence/modification hypotheses and available fragment evidence. Use the vendor's release-specific input formats, system requirements and license terms.
