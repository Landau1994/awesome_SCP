# msqrob2

## Overview

msqrob2 is an R package for differential quantitative proteomics based on peptide-level linear models. By modeling peptide intensities and aggregating them to protein-level inference, it stays robust to the high missingness and sparse quantification typical of single-cell proteomics. It was one of the statistical engines used in the HUPO inter-laboratory SCP benchmarking study.
