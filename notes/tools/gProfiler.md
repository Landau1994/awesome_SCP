# g:Profiler

## Overview

g:Profiler is a web toolkit for functional enrichment, identifier conversion and related gene-list analyses. Official programmatic clients include the R package gprofiler2 and Python package gprofiler-official.

## Conditions and Limitations

Record the organism, identifier namespace, background universe and annotation version. Enrichment is sensitive to the chosen background and does not prove pathway activation or causal regulation.
