# scplainer

## Overview

scplainer (SCP-based Linear modeling Approach for Interpretable aNd Explorable Results) uses linear models to interpret MS-based single-cell proteomics data: variance partitioning across biological and technical variables, differential abundance analysis, and component analysis, with streamlined visualization. Implemented in the [[scp Package]] Bioconductor framework by the same group.

> [!cite] Primary Reference
> Vanderaa & Gatto (2025) *Genome Biology*
> DOI: [10.1186/s13059-025-03713-4](https://doi.org/10.1186/s13059-025-03713-4)
