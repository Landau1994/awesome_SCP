# SCeptre

## Overview

The official project is [bfurtwa/SCeptre](https://github.com/bfurtwa/SCeptre), a Python extension of Scanpy for multiplexed single-cell proteomics. Installation is from this repository; do not assume the similarly named PyPI package is this tool. The README reports testing on Ubuntu 20.04.1 LTS.

SCeptre is a software/workflow entry for single-cell proteomics data processing.
