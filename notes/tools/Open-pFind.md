# Open-pFind

**An open-search oriented proteomics identification engine for comprehensive peptide discovery.**

## Overview

Open-pFind is the default open-search workflow integrated into [[pFind3]], allowing expanded search spaces for unexpected modifications and other peptide variations. pFind 3 also offers a restricted search mode.

## Key Features

- **Open Search Capability**: Captures unanticipated mass shifts.
- **Large Search Space Handling**: Supports broad identification tasks.
- **High-Coverage Discovery**: Useful for exploratory proteomics.
- **Environment**: The official pFind 3 release requires 64-bit Windows and version-specific dependencies (including .NET and, for quantitation, JRE).

## Input/Output

**Input:**

- Raw/mzML files
- FASTA and modification settings

**Output:**

- PSM/peptide/protein identifications
- Open-search mass-shift results
