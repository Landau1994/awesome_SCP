# MAGeCK

## Overview

MAGeCK (Model-based Analysis of Genome-wide CRISPR-Cas9 Knockout) analyzes pooled CRISPR screens. It can count guide reads and test guide/gene enrichment or depletion between experimental conditions.

## Conditions and Limitations

The guide library, comparison/design, normalization and controls must match the screen. It analyzes perturbation-screen abundance, not protein-spectrum identification; CRISPR activation applications require their own study design.
