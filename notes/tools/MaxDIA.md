# MaxDIA

## Overview

MaxDIA is the data-independent acquisition analysis module of [[MaxQuant]]. It supports library-based and library-free (discovery) DIA workflows, including predicted spectral libraries (the original discovery-DIA paper uses DeepMass:Prism), with end-to-end identification and quantification inside the MaxQuant environment.
