# DESeq2

## Overview

DESeq2 is an R/Bioconductor package for differential analysis of sequencing count data, using negative-binomial models, dispersion estimation and shrinkage methods.

## Conditions and Limitations

Provide suitable unnormalized counts and a valid experimental design. Log-transformed protein intensities are not the default observation type; a study using DESeq2 for another data type needs a specific justification.
