# scPROTEIN

## Overview

scPROTEIN is a contrastive-learning framework that learns cell-level embeddings from single-cell proteomics data, supporting clustering and downstream analysis while modelling peptide-level uncertainty and learning graph representations. Robustness in a particular sparse dataset still requires validation.
