# scikit-learn

## Overview

scikit-learn is the standard open-source machine-learning library for [[Python]], providing classification, regression, clustering, dimensionality reduction, and model-evaluation tools. Used across proteomics pipelines for classifier training and benchmarking (e.g., in AlphaDIA model evaluation and ProFormer classification).
