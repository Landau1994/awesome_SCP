# CIBERSORTx

## Overview

CIBERSORTx estimates cell-type composition and cell-type-specific gene expression from bulk expression profiles using reference signatures, including signatures derived from single-cell RNA data.

## Conditions and Limitations

Reference coverage, cell states and batch differences affect estimates. The documented expression deconvolution model should not be assumed directly valid for MS protein-intensity matrices.
