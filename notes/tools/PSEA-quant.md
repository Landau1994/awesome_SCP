# PSEA-Quant

## Overview

PSEA-Quant performs protein-set enrichment analysis on quantitative proteomics measurements, including replicated label-free and label-based experiments. The original work describes a Java implementation and a web interface.

## Conditions and Limitations

Protein identifiers, abundance/variation estimates and replicate structure affect enrichment. The linked original paper identifies the historical tool; current hosting and runtime compatibility of the original service were not confirmed.
