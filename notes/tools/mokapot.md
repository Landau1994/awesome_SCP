# mokapot

## Overview

mokapot is a Python tool for semi-supervised rescoring and confidence estimation of peptide-spectrum matches, using Percolator-style learning and target-decoy information.

## Conditions and Limitations

It requires suitable upstream search results/features and decoys. It is not a raw-spectrum search engine, and model fitting must avoid information leakage and invalid FDR assumptions.
