# Snakemake

## Overview

Snakemake is a [[Python]]-based workflow management system for building reproducible, scalable bioinformatics pipelines. It is used by single-cell proteomics analysis pipelines such as [[CASPA]] to chain processing steps from raw data to quantification matrices.
