# SpectMHC

## Overview

SpectMHC creates targeted MHC peptide databases from a parent FASTA using locally installed netMHC/NetMHCpan predictions. The resulting database can support downstream immunopeptidomics searches.

## Conditions and Limitations

The historical scripts depend on the external predictor and its supported versions. A prediction-filtered search space can exclude genuine ligands; downstream identification still requires suitable false-discovery control.
