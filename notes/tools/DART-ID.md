# DART-ID

## Overview

DART-ID (Data-driven Alignment of Retention Times for Identification) re-scores peptide-spectrum matches across many (single-cell) LC-MS runs using retention-time information, raising confident identifications in sparse SCP datasets. Developed in the Slavov lab and used in early [[SCoPE2]]-era workflows.
