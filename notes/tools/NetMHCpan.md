# NetMHCpan

## Overview

NetMHCpan predicts peptide binding and ligand likelihood for MHC class I molecules using neural networks. It accepts peptide sequences or protein FASTA plus MHC alleles/sequences, and returns binding/ligand scores and percentile ranks.

## Conditions and Limitations

Specify the model version, allele and peptide-length settings. Predicted binding or presentation is not proof of an immunogenic T-cell response; MHC class II prediction uses a different tool (NetMHCIIpan).
