# AlphaTims

## Overview

AlphaTims is an open-source Python package for fast, memory-efficient access to Bruker timsTOF raw data (`.d` folders), exposing PASEF frames, scans, and precursor data through a pandas-like interface. It belongs to the Alpha ecosystem from the Mann lab, alongside [[AlphaPept]], [[AlphaDIA]], [[AlphaPeptDeep]], and [[AlphaBase]].
