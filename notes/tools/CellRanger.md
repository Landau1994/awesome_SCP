# Cell Ranger

## Overview

Cell Ranger is 10x Genomics software for processing supported Chromium single-cell sequencing assays, including gene expression, V(D)J and Feature Barcode applications. It processes sequencing reads into assay-specific counts and quality-control reports.

## Conditions and Limitations

Use the release and reference compatible with the assay chemistry. Antibody-derived Feature Barcode counts are distinct from mass-spectrometry intensities; Cell Ranger does not search MS raw files.
